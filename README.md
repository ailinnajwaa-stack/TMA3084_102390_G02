# Pizza Ordering Program

This is a simple Dart program for ordering pizzas.

## Pizza Prices

* Small: 5 USD
* Medium: 7 USD
* Large: 10 USD

## Features

* Enter the pizza size.
* Enter the quantity.
* Calculate the total payment.
* Continue ordering if needed.
* Display an error for an invalid pizza size.

## How to Run

1. Make sure Dart is installed.
2. Open the project folder in the terminal.
3. Run:

```bash
dart run pizza.dart
```
